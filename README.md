# lazysnail_web

Source of [lazysnail.net](https://www.lazysnail.net), the blog of Arnaud Gastelblum: Microsoft Fabric,
Power BI, data modelling, and the tools I build with AI.

Built with [Jekyll](https://jekyllrb.com) and a customised copy of the
[Just the Docs](https://github.com/just-the-docs/just-the-docs) theme (MIT licence, see `LICENSE.txt`).
GitHub Pages publishes the `main` branch.

Local preview: `bundle install`, then `bundle exec jekyll serve` and open http://localhost:4000.
